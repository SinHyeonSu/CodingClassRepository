# 서울 시간별 기상 관측: 두 7일 기간 비교

## 관측소·기간·출처

- 관측소: 108 (서울), 두 기간 모두 동일
- 기존 기간: 2025-10-01 00:00 ~ 2025-10-07 23:00 (KST)
- 변경 기간: 2025-10-08 00:00 ~ 2025-10-14 23:00 (KST)
- 출처: 기상청 API허브 → 종관기상관측(ASOS) → 1.2 시간자료(기간 조회)
- 공식 설명: https://apihub.kma.go.kr/apiList.do?apiSeq=2

## 실행 방법

Python이 설치된 환경에서 이 폴더의 터미널을 열어 실행합니다.

```powershell
py -m pip install requests matplotlib
py collect_weather.py
py plot_weather.py
```

수집 코드는 실행 중 getpass.getpass()로 인증키를 입력받습니다. 입력 문자는 화면에 표시되지 않습니다.
그래프 코드는 저장된 CSV만 읽으며 API를 다시 호출하지 않습니다.

## 변경 내용과 파일명 일치

수집 코드의 START_TIME은 202510080000, END_TIME은 202510142300으로 변경했으며 자료 시각 검증 범위도 같은 상수를 사용합니다.
수집 코드의 CSV 출력과 그래프 코드의 CSV 입력은 모두 weather_20251008_20251014.csv입니다.
새 그래프 파일은 temperature_20251008_20251014.png이며 기존 결과는 덮어쓰지 않습니다.

| 구분 | 기존 기간 | 변경 기간 |
| --- | --- | --- |
| CSV | weather.csv | weather_20251008_20251014.csv |
| 기온 그래프 | temperature.png | temperature_20251008_20251014.png |

## 주요 함수와 자료 처리

- collect_weather.py: parse_weather는 # 설명 줄을 분리하고 TM(1), WS(4), TA(12), HM(14)를 검증한 뒤 공백으로 자료를 나누고 시각 변환·정렬을 수행합니다. save_weather는 원본을 별도 보관하고 CSV와 결측·중복 요약을 저장·출력합니다. redact는 키와 키가 포함될 수 있는 주소를 숨깁니다.
- plot_weather.py: load_temperature는 CSV의 시각·기온을 읽고 정렬하며 중복을 검사합니다. fill_hourly_gaps는 첫 관측부터 마지막 관측 사이를 1시간 간격으로 채웁니다. plot_temperature는 결측 구간에서 선을 끊고 PNG를 저장한 뒤 화면에 표시합니다.

CSV 열은 datetime, temperature_C, humidity_pct, wind_speed_ms 순서입니다. 행 인덱스 없이 utf-8-sig로 저장하고 결측은 빈 값으로 둡니다.
기온의 -9°C 같은 정상 음수는 유지하며 -99 이하의 결측 코드를 비웁니다. 습도·풍속의 음수는 결측으로 처리합니다.
중복 자료는 수집 시 삭제하지 않고 개수를 안내하며 그래프 작성 시 중복 시각이 있으면 중단합니다.
원본 응답은 weather_raw_날짜_시간.txt로 별도 보관합니다.

## 그래프 해석 (두 문장)

기존 기간의 시간별 기온은 15.4~25.7°C 범위이며, 10월 1~2일의 일중 변화와 6~7일의 기온 하강이 나타납니다.
새 기간의 시간별 기온은 13.9~27.7°C 범위로, 두 그래프의 높이와 변동을 통해 기간별 기온 차이를 확인할 수 있습니다.

## 두 기간의 차이 (한 문장)

10월 8~14일의 평균 기온은 18.82°C로, 10월 1~7일의 20.40°C보다 1.58°C 낮았다.
