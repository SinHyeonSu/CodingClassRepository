# 힘 단위 변환기

Python Tkinter로 만든 간단한 데스크톱 프로그램입니다. 입력한 힘을 `N`, `kN`, `kgf` 단위로 변환해 한 번에 보여줍니다.

## 실행 환경

- Python 3
- Tkinter (일반적인 Windows용 Python 설치에 포함되어 있습니다)

추가 패키지 설치는 필요하지 않습니다.

## 실행 방법

프로젝트 폴더에서 다음 명령을 실행합니다.

```bash
python force_converter.py
```

## 사용 방법

1. 숫자 입력란에 변환할 힘의 값을 입력합니다.
2. 입력 단위에서 `kN`, `N`, `kgf` 중 하나를 선택합니다. 기본값은 `kN`입니다.
3. **변환**을 누르면 결과가 `N`, `kN`, `kgf`로 표시됩니다.
4. **초기화**를 누르면 입력값과 결과가 지워지고 입력 단위가 `kN`으로 돌아갑니다.

숫자가 아닌 값을 입력하면 오류 메시지가 표시됩니다. 결과는 소수점 둘째 자리까지 표시됩니다.

## 변환 기준

- `1 kN = 1000 N`
- `1 kgf = 9.80665 N`

프로그램은 선택한 입력 단위를 뉴턴(`N`)으로 환산한 뒤, 뉴턴을 기준으로 나머지 단위를 계산합니다.
