# 힘 변환 및 하중 분석

Python으로 만든 힘 단위 변환기와 CSV 하중 분석기입니다.

## 실행 환경

- Python 3
- `load_analyzer.py`에 필요한 패키지: `pandas`, `matplotlib`
- `force_converter.py`에는 별도 패키지가 필요하지 않습니다. Tkinter는 일반적인 Windows Python 설치에 포함됩니다.

분석기 패키지는 다음 명령으로 설치합니다.

```bash
python -m pip install pandas matplotlib
```

## 힘 단위 변환기

프로젝트 폴더에서 실행합니다.

```bash
python force_converter.py
```

숫자를 입력하고 `kN`, `N`, `kgf` 중 단위를 선택한 다음 **변환**을 누르면 세 단위의 값이 표시됩니다. **초기화**를 누르면 입력과 결과가 지워집니다.

변환 기준은 `1 kN = 1000 N`, `1 kgf = 9.80665 N`입니다. 결과는 소수점 둘째 자리까지 표시됩니다.

## 하중 데이터 분석기

프로젝트 폴더에서 실행합니다.

```bash
python load_analyzer.py
```

분석기는 스크립트와 같은 폴더의 `load_data.csv`를 읽습니다. CSV에는 `time_s`와 `force_N` 열이 필요합니다.

```csv
time_s,force_N
0,0
1,100
2,250
```

단면적은 `load_analyzer.py`의 `area_mm2` 값으로 설정하며, 현재 값은 `100 mm²`입니다. 평균 수직 응력은 다음과 같이 계산합니다.

```text
stress_MPa = force_N / area_mm2
1 N/mm² = 1 MPa
```

분석기는 데이터 개수, 최대 하중과 시간, 최대 평균 수직 응력과 시간을 출력합니다. 또한 기준 응력 `8 MPa`를 **초과하는** 데이터 행의 개수를 출력합니다. 기준값은 `load_analyzer.py`의 `REFERENCE_STRESS_MPA`에서 변경할 수 있습니다.

응력 그래프는 각 데이터 지점을 표시하고 선으로 연결합니다. 최대 응력 지점은 빨간 마커와 응력값·시간 주석으로 강조됩니다. x축은 `Time(s)`, y축은 `Stress(MPa)`이며, x축에는 2초 간격, y축에는 1 MPa 간격의 희미한 실선 격자가 표시됩니다.

### 입력 오류 처리

`time_s` 또는 `force_N` 값이 비었거나 숫자가 아니면 원본 CSV의 행 번호와 문제 값을 출력하고 해당 행을 제외합니다. 열 개수가 맞지 않거나 CSV 형식을 읽을 수 없는 행도 제외합니다. 제외한 행 수와 유효한 데이터 수를 출력한 뒤 유효한 행만으로 분석을 계속합니다.

유효한 데이터가 없으면 계산과 결과 생성을 중단합니다. 원본 CSV는 수정하지 않습니다.

### 생성 파일

- `load_result.csv`: `time_s`, `force_N`, `stress_MPa` 열을 저장합니다.
- `stress_plot.png`: 시간-응력 그래프를 저장합니다.

## 하중 분석 GUI

프로젝트 폴더에서 GUI를 실행합니다.

```bash
python load_analyzer_gui.py
```

**CSV 찾아보기**로 입력 파일을 선택한 뒤 단면 종류와 치수를 입력하고 **분석**을 누릅니다. 화면에 선택한 CSV 경로와 유효 데이터 수가 표시되며, 분석 결과로 단면적, 최대 하중, 최대 응력, 최대 응력이 발생한 시간이 나타납니다. 하단 그래프에는 시간에 따른 응력이 표시되고 최대 응력 지점이 강조됩니다. 단위는 치수 `mm`, 단면적 `mm²`, 하중 `N`, 응력 `MPa`, 시간 `s`입니다. 응력은 `force_N / area_mm2`로 계산하며 `1 N/mm² = 1 MPa`입니다.

GUI는 CSV의 헤더에서 `time_s`와 `force_N` 열을 이름으로 찾습니다. 열 순서는 상관없으며 추가 열이 있어도 됩니다. 시간과 하중은 숫자여야 합니다. 예를 들어 다음 형식으로 입력합니다.

```csv
time_s,force_N
0,0
1,100
2,250
```

### 단면 종류와 입력 치수

모든 치수는 양수이며 단위는 `mm`입니다. 선택한 단면에 필요한 입력칸만 표시됩니다. 초기 입력값은 예시값이며 필요에 따라 바꿀 수 있습니다.

| 단면 | 입력 치수 | 단면적 `A` (`mm²`) | 유효 조건 |
|---|---|---|---|
| 사각형 | 폭 `b`, 높이 `h` | `b × h` | `b > 0`, `h > 0` |
| 원형봉 | 지름 `d` | `π × d² / 4` | `d > 0` |
| 원형관 | 외경 `D`, 두께 `t` | `π × [D² − (D − 2t)²] / 4` | `D > 0`, `t > 0`, `2t < D` |
| 사각형관 | 외측 폭 `B`, 외측 높이 `H`, 두께 `t` | `B × H − (B − 2t) × (H − 2t)` | `B > 0`, `H > 0`, `t > 0`, `2t < B`, `2t < H` |
| H형강 | 전체 높이 `H`, 플랜지 폭 `B`, 웨브 두께 `tw`, 플랜지 두께 `tf` | `2 × B × tf + (H − 2tf) × tw` | 모든 치수 `> 0`, `2tf < H`, `tw < B` |

사각형관 계산은 안쪽 모서리의 곡률을 무시한 이상화 단면입니다. H형강 계산도 플랜지와 웨브 접합부의 필렛을 무시한 이상화 단면입니다.

### GUI 입력 오류 처리

- 치수 입력이 비어 있거나 숫자가 아니면 해당 치수의 입력을 안내합니다.
- 치수가 0, 음수 또는 유한하지 않은 값이면 양수 입력을 안내합니다.
- 원형관의 `2t ≥ D`, 사각형관의 `2t ≥ B` 또는 `2t ≥ H`, H형강의 `2tf ≥ H` 또는 `tw ≥ B`이면 조건을 안내하고 계산 및 그래프 갱신을 중단합니다.
- 잘못된 입력을 고친 뒤 **분석**을 다시 누르면 같은 CSV로 다시 계산할 수 있습니다. 치수 오류만으로 선택한 CSV나 유효 데이터 수는 지워지지 않습니다.
- CSV에 필요한 열이 없거나 읽을 수 없으면 오류를 표시합니다. 형식 오류, 열 개수 불일치, 숫자가 아니거나 유한하지 않은 시간·하중이 포함된 행은 제외하며 유효 행 수와 제외 행 수를 표시합니다. 유효한 행이 없으면 분석할 수 없습니다.

GUI에는 Tkinter와 Matplotlib가 필요합니다. Tkinter는 일반적인 Windows Python 설치에 포함되며, Matplotlib가 설치되지 않았다면 다음 명령으로 설치합니다.

```bash
python -m pip install matplotlib
```
